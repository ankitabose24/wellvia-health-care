Wellvia

Industry: Healthcare / Hospital / Diagnostics / Wellness
Objective: A modern, patient-focused healthcare website for Wellvia, designed around the idea of making healthcare feel more accessible, calm, trustworthy, and easy to navigate. The site brings healthcare services, specialist consultations, diagnostics, health packages, facilities, doctors, testimonials, and appointment booking together in one responsive digital experience.

Tagline: The path to better health and wellness.

Live Demo: [https://wellvia-health-care.vercel.app/](https://wellvia-health-care.vercel.app/)

Technologies Used

-HTML5 — semantic structure across the main healthcare sections, single-page layout, navigation, content blocks, service information, doctor profiles, appointment form, and contact details
-CSS3 — custom properties, Flexbox/Grid, responsive breakpoints, soft-radius cards, subtle glass-inspired surfaces, gradients, shadows, transitions, responsive medical imagery, and mobile layouts
-JavaScript (ES6+, vanilla, no frameworks) — opening experience, video handling, scroll-aware navigation, mobile menu, smooth navigation, interactive UI elements, appointment form validation, testimonial interactions, and responsive behaviour
-HTML5 Video — immersive Wellvia opening experience using the provided healthcare introduction video
-Google Fonts — modern and classic typography pairing for the Wellvia visual identity
-Responsive Web Design — adaptive layouts for desktop, tablet, and mobile devices

File Description

`index.html` Contains the complete Wellvia website structure, navigation, hero, healthcare services, doctors, health packages, testimonials, facilities, appointment section, contact information, and footer.

`style.css` Contains the complete visual system — Wellvia colour palette, typography, responsive layouts, healthcare cards, grids, medical imagery positioning, opening screen, transitions, and mobile adaptations.

`script.js` Contains the website's JavaScript functionality — opening video experience, navigation, mobile menu, scroll interactions, form validation, interactive elements, and UI behaviour.

`assets/logo.jpeg` Wellvia brand logo used throughout the opening screen, navigation, hero, and footer.

`assets/capsules.jfif` Healthcare capsule artwork used as a static decorative visual within the hero layout.

`assets/stethoscope.jfif` Medical stethoscope artwork used as a subtle static background element.

`assets/opening.mp4` Opening video used for the Wellvia introductory experience. 

`README.md` Project documentation.

How to Run

Open `index.html` directly in any modern browser, or serve the folder locally:

```bash
npx serve .
```
You can also use VS Code Live Server:

Open the project folder in VS Code.
Install the Live Server extension.
Right-click `index.html`.
Select Open with Live Server.
The website will open in your browser.

No build step, no dependencies, and no external JS libraries — everything is plain HTML/CSS/JS plus Google Fonts loaded via CDN.

Notes on Design Choices

* Soft lavender and white tones create a calm, clean, and trustworthy healthcare feel.
* Rounded cards, subtle shadows, and minimal effects give the website a modern yet classic appearance.
* The Wellvia logo is used consistently for strong brand identity.
* Static capsule and stethoscope visuals add a healthcare touch without distracting from the content.
* Responsive layouts ensure the design works smoothly on both desktop and mobile devices.
* The opening video provides a professional and engaging introduction to the Wellvia brand.
